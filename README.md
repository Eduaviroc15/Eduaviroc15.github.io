# Respaldos Servidor

Herramienta privada de administración para crear y almacenar
copias de seguridad cifradas de los sistemas Maira y Óptica C&Q.

Google Drive se utiliza como almacenamiento externo para
recuperar los datos si el servidor deja de funcionar.

La conexión solicita acceso únicamente a los archivos y carpetas
creados por la aplicación mediante Google Drive API.

Esta herramienta es de uso privado del administrador.
No ofrece registro público ni acceso público a los respaldos.
